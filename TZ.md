# Техническое задание: веб-приложение «Нумератор»

Версия 1.3 — рабочая спецификация

## 1. Назначение

Веб-приложение формирует нумерацию для печатной продукции. Пользователь задаёт диапазон номеров, количество мест на печатном листе, шаблон номера и название столбца. Приложение показывает таблицу «На спуск» и позволяет скачать TXT двумя способами:
- «На спуск» — экспорт в порядке чтения таблицы слева направо, строка за строкой.
- «Согласование» — обычная последовательность от начального до конечного номера.

Приложение должно работать в браузерах на macOS и Windows.

## 2. Параметры

- Начало нумерации: целое число, например `8400`.
- Конец нумерации: целое число, например `8500`, включительно.
- Мест на печатном листе: положительное целое число, например `6`.
- Шаблон номера: по умолчанию `$$$$`.
- Название столбца: по умолчанию `nomer`; пользователь может изменить его.

Название столбца записывается в первой строке экспортируемого файла.

## 3. Правила шаблона номера

Символ `$` обозначает числовую часть номера.

- Шаблон должен содержать ровно одну непрерывную группу из одного или нескольких символов `$`.
- Количество символов `$` задаёт минимальную ширину числовой части.
- Если число короче маски, слева добавляются нули.
- Если число длиннее маски, оно не обрезается.
- Все символы за пределами группы `$` сохраняются буквально, включая другие цифры, буквы, пробелы и знаки препинания.
- Шаблон без `$` или с несколькими отдельными группами `$` считается ошибочным.

Примеры для числа `8400`:
- `$$$$` → `8400`
- `П$$$$$` → `П08400`
- `П-$$$$$-А` → `П-08400-А`
- `ABC12-$$$$-99` → `ABC12-8400-99`
- `Заказ № $$$$ / 2026` → `Заказ № 8400 / 2026`

## 4. Предварительный просмотр

Таблица всегда отображается в формате «На спуск», независимо от выбранной кнопки экспорта.

- Каждый столбец соответствует одному месту на печатном листе.
- Номера в каждом столбце идут последовательно сверху вниз.
- Таблица автоматически пересчитывается при изменении параметров.
- Последняя строка может быть неполной.
- Значения больше конечного номера не отображаются.
- Таблица размещается в области ограниченной высоты и ширины.
- При необходимости появляются вертикальная и горизонтальная прокрутки.
- Заголовки столбцов остаются видимыми при вертикальной прокрутке.
- Над таблицей показывается строка `Количество номеров — X`, где `X = E - S + 1`.

Для диапазона `8400–8500` общее количество номеров — `101`.

## 5. Алгоритм «На спуск»

Все целые числа от `S` до `E` включительно должны присутствовать в таблице ровно один раз.

- `N` — количество столбцов (позиций).
- Числа распределяются последовательно по столбцам сверху вниз: сначала заполняется первый столбец, затем второй и так далее.
- Последний столбец может быть заполнен не полностью; незаполненные ячейки остаются пустыми.
- При экспорте «На спуск» таблицу читать по строкам: слева направо, затем сверху вниз. Пустые ячейки пропускать.

Пример: `S = 1`, `E = 7`, `N = 3`.

| Место 1 | Место 2 | Место 3 |
|---:|---:|---:|
| 1 | 4 | 7 |
| 2 | 5 | |
| 3 | 6 | |

Экспорт «На спуск»: `1, 4, 7, 2, 5, 3, 6`.

## 6. Алгоритм «Согласование»

Экспортировать обычную последовательность `S, S+1, S+2, …, E`, включая оба граничных номера.

Предварительный просмотр остаётся в формате «На спуск» и при нажатии этой кнопки не меняется.

## 7. Экспорт TXT

Обе кнопки создают отдельный текстовый файл:
- кодировка UTF-8;
- первая строка — название столбца;
- каждый номер записывается с новой строки;
- шаблон применяется к каждому номеру;
- пустые строки, фиктивные номера и значения за пределами диапазона не записываются.

Примеры имён файлов:
- `на спуск_8400—8500.txt`
- `согласование_8400—8500.txt`

Название столбца не влияет на имя файла.

## 8. Проверки ввода

Проверять:
- начало и конец — целые числа;
- начало не больше конца;
- количество мест — положительное целое число;
- шаблон содержит ровно одну непрерывную группу `$`;
- название столбца не пустое.

При некорректных данных показывать понятное сообщение и не выполнять экспорт до исправления.

Не вводить собственное ограничение на размер диапазона. Учитывать, что очень большие диапазоны могут замедлять браузер и требовать много памяти.

## 9. Технологии и развёртывание

Предлагаемый стек:
- React + Vite — интерфейс и сборка;
- JavaScript — расчёты, таблица и экспорт;
- Git — история изменений;
- Cursor — среда разработки;
- Timeweb Cloud VPS — последующее размещение;
- Namecheap — управление доменом.

На первом этапе приложение работает без backend и базы данных: расчёты и создание TXT выполняются в браузере. После локальной разработки и тестирования приложение будет опубликовано на VPS с подключением домена и HTTPS.

Разрабатывать небольшими проверяемыми этапами:

4. Реализовать оба экспорта TXT.

Не менять требования и алгоритмы самостоятельно: при неоднозначности сначала задавать вопрос.
